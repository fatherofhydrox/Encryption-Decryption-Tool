# 🔐 Encryption & Decryption Tool

A simple command-line based tool developed in Python to perform secure encryption and decryption of data using basic cryptographic techniques.

---

## 📌 Features
- Encrypts plain text into secure ciphertext  
- Decrypts ciphertext back to original text  
- Implements hashing (SHA-256) for data integrity  
- Lightweight and easy to use CLI tool  

---

## 🛠️ Technologies Used
- Python  
- hashlib (for SHA-256 hashing)  

---

## ⚙️ How It Works
1. User inputs text or file  
2. Tool applies encryption algorithm  
3. Encrypted output is generated  
4. Decryption reverses the process to original text  
5. Hashing ensures data integrity
